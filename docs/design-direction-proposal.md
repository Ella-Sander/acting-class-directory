# Voxline NYC: the coach score

**Status:** Implemented in the local application.

## Brand and visual direction

Voxline NYC presents its vocal-coach directory as an editorial music score: a charcoal masthead, warm ivory paper, ink-black staves and notes, with a restrained oxblood accent. Flowing staff lines and musical notation frame the centered directory title, while the coach and class listings become note markers with floating score labels.

## Page and interaction

- The centered hero pairs a large editorial title and primary search with a hand-drawn-style staff motif.
- A compact directory workspace places service-type and verified lesson filters beside the score-like results.
- Search, location, technique, budget, format, sorting and listing-type controls continue to use existing directory logic.
- Each notation marker is a semantic button that opens its existing coach or class profile.
- Responsive layouts collapse the filter sidebar into the existing mobile filter sheet, while notation rows adapt to narrow screens.

## Accessibility and functionality

Directory data, profile routes, contributions and metadata are unchanged. Decorative score art is hidden from assistive technology; listings retain accessible names and keyboard focus. Reduced-motion preferences are respected, and mobile layouts avoid horizontal page overflow.
