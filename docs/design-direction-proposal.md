# Design direction and page structure

**Status:** Direction implemented in the local application following approval.

The current local page is a visual foundation specimen, not the finished homepage or directory. It establishes a distinct editorial direction for review before those product surfaces are built.

## Visual direction

- Brand working name: **Acting Class Directory**.
- Mood: independent arts journal meets thoughtful city guide; premium, calm and actor-focused.
- Palette: warm paper `#f5f2eb`, ink `#24231f`, muted wine `#653d43`, brass `#b08b58`, and fine stone rules `#d9d4ca`.
- Type: expressive literary serif for display and listing names; clear sans serif for controls, labels and metadata.
- Layout: generous margins, compact editorial labels, strong typographic hierarchy, image-led provider/offering cards, minimal chrome.
- Mobile: single-column reading flow, large tap targets, no fixed desktop filter rail, and a dedicated filter sheet when the directory is implemented.
- Imagery: only official provider-associated imagery with provenance; otherwise restrained branded placeholders.

## Proposed homepage structure

1. Slim identity/navigation header with browse, how it works, and provider submission.
2. Editorial introduction and prominent search by provider, class, coach or technique, with location.
3. Featured studios and schools, classes/workshops, and coaches.
4. Browse training types and verified techniques.
5. A short “how the directory works” explanation: source-based listings, transparent pricing, and editorial review.
6. Provider submission and claim-profile call to action.
7. Footer for about, contact, policies and useful links.

## Proposed directory structure

- Search and result count at the top.
- Fundamental filters: listing type, NYC borough/online, training type, verified technique, verified format, and numeric budget with price basis.
- Results cards in the main column, sort by relevance/price/name, with active filter chips and reset.
- Mobile filters in a drawer with applied-filter count.
- Profile pages share provider identity and source evidence; classes remain distinct offerings and link to studios and instructors.
- Further filters such as level, schedule, duration, instruction mode and admission requirements wait for measured seed coverage.

## Implemented foundation

The homepage, directory, listing type routes, filters, provider/offering profiles, submissions, claims, and local admin review are now implemented using this direction. Image areas use branded placeholders; only sourced text and URLs are seeded. Full feature development is paused for the user's next approval.
